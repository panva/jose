| Interface | Description |
| ------ | ------ |
| [LocalJWKSet](interfaces/LocalJWKSet.md) | A key resolver created by [createLocalJWKSet](functions/createLocalJWKSet.md). |

## Functions

| Function | Description |
| ------ | ------ |
| [createLocalJWKSet](functions/createLocalJWKSet.md) | Creates a resolver for a locally available JSON Web Key Set. |
