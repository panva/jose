# composable/jws/general/sign

Composable General JWS signing.

## Interfaces

| Interface | Description |
| ------ | ------ |
| [GeneralSignature](interfaces/GeneralSignature.md) | Used to build a General JWS object's individual signatures. |
| [GeneralSignConstructor](interfaces/GeneralSignConstructor.md) | Constructor returned by [composeGeneralSign](functions/composeGeneralSign.md). |
| [GeneralSignInstance](interfaces/GeneralSignInstance.md) | Interface implemented by a composed GeneralSign instance. |

## Functions

| Function | Description |
| ------ | ------ |
| [composeGeneralSign](functions/composeGeneralSign.md) | Composes a GeneralSign constructor supporting the selected JWS algorithms. |
