# composable/jwe/flattened/encrypt

Composable Flattened JWE encryption.

## Interfaces

| Interface | Description |
| ------ | ------ |
| [ComposedFlattenedEncrypt](interfaces/ComposedFlattenedEncrypt.md) | A Flattened JWE encryptor whose headers suggest the selected algorithms. |
| [ComposedFlattenedEncryptConstructor](interfaces/ComposedFlattenedEncryptConstructor.md) | Constructor for a Flattened JWE encryptor with the selected header type. |
| [ComposedJWEHeader](interfaces/ComposedJWEHeader.md) | A JWE header with IntelliSense for the algorithms supplied to a composer. |

## Functions

| Function | Description |
| ------ | ------ |
| [composeFlattenedEncrypt](functions/composeFlattenedEncrypt.md) | Composes a Flattened JWE encryptor class from the selected JWE algorithm factories. |
