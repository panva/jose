# jws/general/sign

Signing JSON Web Signature (JWS) in General JSON Serialization

## See

[RFC 7515, Section 7.2.1](https://www.rfc-editor.org/info/rfc7515/#section-7.2.1)

## Classes

| Class | Description |
| ------ | ------ |
| [GeneralSign](classes/GeneralSign.md) | Produces general JWS JSON Serialization using digital signatures or MACs. |

## Interfaces

| Interface | Description |
| ------ | ------ |
| [Signature](interfaces/Signature.md) | Configures an individual JWS Signature (digital signature or MAC) in a General JWS. |
